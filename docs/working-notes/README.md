# Working notes

These files make exploratory sessions resumable. They may preserve useful
observations, candidate rules, tool findings, or a parked line of work without
promoting that material into strategy, architecture, or an implementation
contract.

Every working note should state its status, what it is useful for, and what
would cause it to be revisited. A note can inform the next session, but current
user direction and canonical documents still take precedence.
